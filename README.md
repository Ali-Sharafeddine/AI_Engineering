# AI Engineering Practice Notebooks

A collection of hands-on Jupyter notebooks exploring core AI engineering concepts and workflows using Python and PyTorch.

This repository documents practical exercises and experiments involving model fine-tuning, tokenization, embeddings, and CPU/GPU performance.

## Notebooks

| Notebook | Description |
|---|---|
| [Fine-tuning Exercise](./FineTuning_Exercise.ipynb) | A hands-on exercise exploring model fine-tuning. |
| [Tokenizer Comparison](./TokenizersComparison.ipynb) | Experiments comparing tokenization approaches and their outputs. |
| [Embeddings Example](./embeddingsExample.ipynb) | Practical exploration of embeddings and their use in AI applications. |
| [GPU vs. CPU Benchmarking](./GPU_CPU_Benchmarking.ipynb) | Experiments comparing execution performance across CPU and GPU environments. |

## Getting Started

1. Clone or download this repository.
2. Open the notebooks in Jupyter Notebook, JupyterLab, or a compatible notebook environment.
3. Install the required Python packages.
4. Run the notebook cells in order and review the outputs.

**Note:** The notebooks may have different dependencies. Check their imports and setup instructions before running them. GPU experiments require access to a compatible GPU environment, and results may vary depending on the hardware and software configuration.

## Learning Objectives

- Explore practical model fine-tuning workflows.
- Understand how tokenizers transform text into model inputs.
- Experiment with embeddings and numerical text representations.
- Investigate differences between CPU and GPU execution.
- Develop practical familiarity with Python-based AI tooling.

## Scope

This is a learning and experimentation repository, rather than a production-ready software package. The notebooks are intended to demonstrate practical exercises and document technical learning.
